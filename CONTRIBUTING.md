# Contribuer à sandia_assurance

Merci de votre intérêt pour le projet `sandia_assurance` ! Ce document explique comment contribuer proprement.

## Processus de contribution

1. Forkez le dépôt sur GitHub.
2. Créez une branche dédiée à votre correctif ou fonctionnalité :
   ```bash
git checkout -b feature/mon-ajout
```
3. Travaillez sur votre branche et faites des commits clairs.
4. Poussez vers votre fork :
   ```bash
git push origin feature/mon-ajout
```
5.Ouvrez une Pull Request vers `main` sur le dépôt principal.

## Bonnes pratiques

- Rédigez des messages de commit simples et explicites.
- Séparez les corrections de bugs et les nouvelles fonctionnalités en branches distinctes.
- Testez votre travail localement avant de proposer la PR.
- Respectez la structure du projet et ne modifiez pas les fichiers inutiles.

## Rapport de bug

Lorsque vous signalez un bug, merci de préciser :

- Le comportement attendu.
- Le comportement observé.
- Les étapes pour reproduire.
- Les erreurs apparaissant dans la console ou les logs.

## Nouvelle fonctionnalité

Pour une nouvelle fonctionnalité, décrivez :

- le besoin utilisateur
- le comportement attendu
- les choix d’implémentation possibles

## Style de code

- Python : respectez la syntaxe standard PEP 8.
- HTML/CSS/JS : structure claire et indentation cohérente.
- Commentez uniquement quand c’est nécessaire.

## Contact

Si vous avez une question, ouvrez une issue sur GitHub.
